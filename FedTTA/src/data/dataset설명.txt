데이터셋 설명 
- 태스크(Task) 구성: 데이터셋당 8개의 서로 다른 NLP 태스크 포함 (예: 요약, 질문 분류, 감성 분석 등).
- 질문 형식: 모든 태스크를 생성형 지시문(Generative Instruction) 형식으로 변환하여 처리 (주관식/객관식 혼합).

데이터 규모 및 샘플링 

Task당 규모: 각 task별로 300개의 train, 200개의 test 인스턴스를 랜덤 샘플링
전체 규모: 연합 데이터셋당 총 1,600개(8 task x 200개)의 테스트 데이터 활용.
Unseen 태스크: 별도의 완전 새로운 3개 태스크(각 200개, 총 600개)를 일반화 성능 측정용

Evaluation 시나리오별 데이터 활용

Personalization: 클라이언트가 학습한 특정 1개 태스크의 200개 데이터로 성능 측정.
Test-time Personalization: 클라이언트가 학습하지 않은 나머지 7개 태스크의 1,400개 + 본인 꺼 200개 = 전체 1,600개 데이터의 평균 성적 측정.
Unseen Generalization: 연합 학습 전체에서 배제된 3개 태스크(600개) 데이터 평균 측정.
- 이건 타 dataset에 있는 category를 찾아서 진행하면 됨. 
예시) Dataset1 기준으로, Summarization, Reading Comprehension, Open Domain QA 활용 = 600개 평균

성능 측정 지표 

ROUGE-1: 생성된 텍스트와 정답 간의 단어 중복도를 측정하는 지표를 사용하여 모든 태스크의 성적을 정량화.
